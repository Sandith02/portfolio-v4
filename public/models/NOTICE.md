# Inner-world figure

`inner-world-figure.glb` is adapted from the MakeHuman Community base mesh,
masculine young-adult targets, default rig and weights, all released under CC0.

Source: https://github.com/makehumancommunity/makehuman
License: https://github.com/makehumancommunity/makehuman/blob/master/LICENSE.ASSETS.md

Source paths:
- makehuman/data/3dobjs/base.obj
- makehuman/data/targets/macrodetails/asian-male-young.target
- makehuman/data/targets/macrodetails/universal-male-young-averagemuscle-averageweight.target
- makehuman/data/rigs/default.mhskel
- makehuman/data/rigs/default_weights.mhw

Adaptation: relaxed floating pose, plain clothing shells, smooth shading,
centered origin, reduced scale, skinned mesh and dark silhouette material.
A floating gesture gently opens the relaxed arms during ascent,
then settles the shoulders, forearms, head and trailing leg into the final pose.
Built with `scripts/build-finale-figure.py` using Blender.

The existing `inner-world-head.glb` keeps its existing Lee Perry-Smith attribution.
